## Editing

- `assets/console.js`: the name, the line under it, and the menu on every page.
- `assets/timeline.js`: the career timeline under each job.
- `assets/projects.js`: project cards on the demos page. Set `live: true` when a repo goes public.
- `style.css`: colors and layout.
- `assets/qr.png` and `assets/qr.svg`: the business card QR code, which points to the home page.

After changing a CSS or JS file, raise the `?v=3` number where that file is linked in the HTML pages so browsers load the new copy.
